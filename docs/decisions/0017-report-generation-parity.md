# ADR-0017: 기존 리포트의 프롬프트와 생성 설정을 복원해요

- 상태: 확정
- 작성·확정일: 2026-10-27
- 확정 근거: 사용자가 기존 리포트와 프롬프트·기타 설정을 동일하게 맞추도록 요청했어요.
- 관련 기록: [ADR-0016](0016-generate-content-video-input.md)을 대체해요. 운영 설정은 [ADR-0015](0015-gemini-production-settings.md)를 유지해요.
- 구현·검증 상태: 프롬프트·요청·후처리를 복원하고 원문과의 오프라인 대조를 통과했어요.
  실제 영상 요청은 HTTP 429로 실패했어요. Worker 배포·제품 API·Android 연동은 하지 않았어요.

## 문제와 현재 상태

앞선 구현은 리포트 프롬프트를 축약하고 출력 상한·제한 시간·응답 검사도 바꿨어요.
[ADR-0016](0016-generate-content-video-input.md)은 실제 생성 성공을 근거로 API 경로까지 변경했어요.
이 변경들은 기존 리포트와 다른 결과를 만드는 요인이며 사용자가 요청한 동일한 생성 조건에 맞지 않아요.

## 결정

- [공통 함수](../../apps/api/src/summary.ts)의 리포트 프롬프트와 영상 제목·URL을 포함한 사용자 프롬프트를 원문 그대로 사용해요.
  1,500자 이상, 3줄 요약·서론·본론·결론·한번 생각해보기 구조와 시간 링크 지시를 복원해요.
- `new GoogleGenAI({ apiKey })`와 `interactions.create`를 사용해요.
  입력은 `processing: "agentic"`인 영상과 프롬프트이고 `store: false`, 요청 옵션은 `signal`만 전달해요.
  출력 토큰 상한·temperature·thinking 설정·재시도 옵션을 추가하지 않고 SDK 기본 동작을 사용해요.
- 기본 제한 시간은 600,000ms예요. 제한 시간을 넘으면 요청 중단과 Promise 경합으로 종료해요.
  모델 입력은 `gemini-3.5-flash-lite`, `gemini-3.6-flash`, `gemini-3.7-flash`로 제한해요.
  현재 운영 모델은 GitHub Variable에 지정한 `gemini-3.6-flash`예요.
- 응답이 `completed`이고 앞뒤 공백을 제거한 본문이 200자 이상인지 검사해요.
  이어서 소문자 `think`·`thinking` 블록을 제거하고 단독 시간 표기를 영상 링크로 바꿔요.
  이미 연결된 링크와 코드블록은 보존해요. 별도의 제목 구조 검사는 제거해요.
- 제목·채널의 oEmbed 조회, URL 검증, 안전한 오류 분류와 사용량 기록은 유지해요.
  [CLI](../../apps/api/tools/summary.ts)는 `api: "interactions"`, `processing: "agentic"`, `timeoutMs`를 기록하고
  결과에는 `interactionId`와 Interactions 사용량을 담아요. 과거 실행 파일은 당시 결과로 보존해요.

## 근거와 대안

2026-10-27 확보한 프롬프트·요청 코드·시간 제한·후처리 원문과 현재 구현을 대조했어요.
가짜 SDK 응답을 사용한 요청 4쌍에서 전체 프롬프트와 옵션이 같았고 Markdown 4개·시간 표기 7개의 결과도 같았어요.
이 대조는 공급자를 호출하지 않았어요. 프롬프트 UTF-8의 SHA-256은
`6936e9d8d7ee7d76a02f9ffd7d558b5f3abdec0551724dab711ba318fcbc9b93`예요.

`generateContent`를 유지하면 앞서 성공한 경로를 계속 쓸 수 있지만 요청한 생성 조건과 달라 채택하지 않아요.
429 이후 해당 경로로 자동 전환하면 실제 사용한 조건이 달라지므로 자동 전환도 추가하지 않아요.

## 가정·한계와 영향

같은 프롬프트와 설정도 생성 결과의 문장·길이·정확성이 매번 같음을 보장하지 않아요.
1,500자·영상 내용 100% 포함은 프롬프트의 지시이며 검증 완료된 품질이 아니에요.
시간 링크 변환은 원본 장면의 시점을 검증하지 않아 `timestampVerification: "unverified"`를 유지해요.

현재 SDK는 고정된 `@google/genai` 2.31.0이에요. 비교 대상의 lockfile·전체 실행 환경은 확인하지 않아
의존성 버전까지 일치한다고 보고하지 않아요. SDK 기본 재시도 때문에 단일 CLI 실행에서 여러 HTTP 요청이 발생할 수 있어요.
출력 토큰 상한을 명시하지 않으므로 이전 4,096토큰 제한보다 출력과 비용이 늘어날 수 있어요.

제품 요약 API·영속 데이터 소비자는 아직 없어 결과 필드 변경의 데이터 마이그레이션은 없어요.
실제 Workers 공급자 호출·모델별 지원 범위·계정 한도와 현재 사용량은 추가 검증이 필요해요.

## 검증과 재검토 조건

2026-10-27 macOS arm64·Bun 1.4.2·SDK 2.31.0·`gemini-3.6-flash`로
[공개 영상](https://www.youtube.com/watch?v=2lv5xHjLx1c)을 실행했어요.
`report-parity-1027a`는 UTC 09:06:52.330 시작, 34,220ms 뒤 기본 재시도 후에도 HTTP 429였어요.
제목·채널은 oEmbed로 확인했고 본문·사용량·구체적인 초과 항목은 받지 못했어요.
실제 계정의 한도·잔여량·비용은 계속 `null`이에요.

요청 경로·모델·출력 상한 미설정·기본 재시도·응답 검사·시간 제한·시간 링크 처리는 workerd의 가짜 응답으로 검사해요.
파일 기록·동시 실행·권한은 Bun에서 검사하고 최종 `mise run check`를 실행해요.
2026-10-27 최종 검사에서 workerd 90개·Bun 도구 16개·공통 도구 49개와
Android 포맷·lint·로컬 테스트·debug 빌드, Terraform의 backend 없는 검사를 통과했어요.
실제 실행 결과와 재현 방법은 [Gemini 가이드](../gemini.md)에 남겨요.
원본 시간 링크와 한도 검증이 남아 #5를 완료로 표시하지 않아요.

SDK 변경이나 품질·비용 요구 변경으로 생성 조건을 바꿔야 하면 동일 영상의 결과를 비교하고 결정 기록을 갱신해요.

## 반론과 변경 이력

- 2026-10-27: 기존 프롬프트·설정이 그대로인지에 대한 지적을 확인했어요. 임의로 변경한 부분을 복원하고 ADR-0016을 대체했어요.
- 2026-10-27: 같은 영상의 실제 요청은 429로 실패했어요. 오프라인 일치 검증과 실제 생성 성공을 구분해요.
