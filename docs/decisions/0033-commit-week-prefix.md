# ADR-0033: 커밋 제목 앞에 강의 주차를 표시해요

- 상태: 확정
- 작성일: 2026-11-09
- 확정일과 근거: 2026-11-09 사용자가 교수님 요구에 따라 `[N주차]`를 제목 맨 앞에 두는 형식을 선택했어요.
- 관련 기록: [ADR-0010](0010-commit-title-format.md)을 대체해요. type·category·PR 번호 규칙은 유지해요.
- 구현·검증 상태: `AGENTS.md`·`CONTRIBUTING.md`와 이 기록을 갱신했어요. 앱 코드·CI·과거 커밋은 바꾸지 않았어요. PR CI와 merge 뒤 적용은 PR에서 확인해요.

## 문제와 현재 상태

숭실대학교 사용자인터페이스 과목 교수님이 앞으로 커밋 메시지에 몇 주차 작업인지 적으라고 요구했어요.
현재 `TYPE(Category): 한국어 요약 (#PR번호)` 형식은 변경 영역과 PR 번호만 보여 주고 주차를 알 수 없어요.
저장소는 [squash-only 협업](../../CONTRIBUTING.md#squash-only-merge)을 사용해 PR 제목이 최종 커밋 제목이 돼요.
커밋 제목만 바꾸면 PR 제목을 놓친 변경은 merge 뒤 주차가 사라져요.
기존 형식은 [ADR-0010](0010-commit-title-format.md)에서 확정했어요.

## 결정

- 커밋과 PR 제목은 `[N주차] TYPE(Category): 한국어 요약 (#PR번호)` 형식이에요.
- `[N주차]`는 강의계획서 기준 주차예요. 작업한 주의 번호를 제목 맨 앞에 적어요.
- 이번 학기 2026-11-09 작업은 사용자가 확인한 `[11주차]`를 사용해요.
- type·category·PR 번호 규칙과 squash-only 방식은 ADR-0010을 유지해요. PR 제목은 PR 번호를 생략해요.
- 여러 주에 걸친 PR은 PR을 만든 주차를 제목에 적고, 본문에서 시작·완료 주차를 설명해요.
- PR 제목과 최종 squash 커밋 제목이 같아지도록 PR 제목에도 주차를 적고, merge 전에 최종 제목을 확인해요.
- 과거 커밋 제목은 바꾸지 않아요. 이 결정 이후 작성하는 커밋과 PR부터 적용해요.

## 근거와 대안

- `[11주차] FEAT(API): ...`는 `git log --oneline`과 GitHub 제목 목록에서 주차가 맨 앞에 보여 주차별 작업을 확인하기 쉬워요. 기존 `TYPE(Category)` 규칙을 그대로 둘 수 있어요.
- `FEAT(API, 11주차): ...`는 category 자리에 일정 정보가 섞여 변경 영역과 주차의 의미가 흐려져 채택하지 않았어요.
- `FEAT(API): [11주차] ...`는 요약 안쪽이라 목록에서 주차가 눈에 덜 띄고 요약만 길어져 채택하지 않았어요.
- 별도 commitlint나 제목 검사 hook은 추가하지 않아요. 문서 규칙과 PR 리뷰로 적용할 수 있고, 도구 설치·유지 비용과 과거 제목 예외 처리를 피할 수 있어요.
- [GitHub squash 설정 문서](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/configuring-commit-squashing-for-pull-requests)를 2026-10-24에 확인했어요. 기본 squash 제목은 설정과 커밋 수에 따라 달라질 수 있어 최종 제목도 확인해요.

## 가정·한계와 영향

- 주차는 강의계획서와 팀이 합의한 학기 기준으로 사람이 판단해요. 자동으로 계산하지 않아요.
- 방학이나 학기 밖 작업의 표기는 정하지 않았어요. 필요해지면 `[방학]` 같은 별도 규칙을 새 기록으로 정해요.
- 최종 squash 제목이 PR 제목과 다르게 생성되면 주차가 빠질 수 있어 merge 전에 제목을 확인해야 해요.
- 기존 커밋·브랜치·배포·CI 동작에는 영향이 없어요.

## 검증과 재검토 조건

- `AGENTS.md`와 `CONTRIBUTING.md`의 형식·예시·ADR 링크가 서로 맞는지 확인해요.
- `git diff --check`로 공백 오류를 확인해요.
- 문서만 바뀌어 앱 검사는 실행하지 않아요. PR CI의 변경 판정과 `quality` 결과는 PR에서 확인해요.
- 주차 표기가 반복해서 빠지거나 혼동되면 commitlint나 PR 제목 검사 도입을 재검토해요.
- 학기·주차 기준이 바뀌면 이 기록을 새 기록으로 대체해요.

## 반론과 변경 이력

- 2026-11-09: 주차를 제목 맨 앞에 두는 안을 선택했어요. category에 섞는 안과 요약에 넣는 안은 목록 가독성과 의미 구분에서 채택하지 않았어요.
