# ADR-0047: 커밋 제목에 주차 다음 작성자 이름을 적어요

- 상태: 확정
- 작성일: 2026-11-23
- 확정일과 근거: 2026-11-23 커밋을 `[##주차][이름] : 한 일` 형식으로 쓰라는 요청을 받았어요. 기존 type·category를 유지하는 형식을 PR로 팀에 공유해요.
- 관련 기록: [ADR-0033](0033-commit-week-prefix.md)을 대체해요. 주차 규칙과 [ADR-0010](0010-commit-title-format.md)의 type·category·PR 번호 규칙은 이어져요.
- 구현·검증 상태: `AGENTS.md`·`CONTRIBUTING.md`와 이 기록을 갱신했어요. 앱 코드·CI·과거 커밋은 바꾸지 않았어요.

## 문제와 현재 상태

- 커밋 제목에 몇 주차 작업인지는 보이지만, 누가 한 작업인지는 보이지 않아요.
- 2026-11-23 커밋을 `[##주차][이름] : 한 일` 형식으로 쓰라는 요청을 받았어요.
- squash merge만 쓰고 있어서 main에는 PR 제목이 최종 커밋 제목으로 남아요.

## 결정

- 커밋과 PR 제목은 `[N주차][이름] TYPE(Category): 한국어 요약 (#PR번호)` 형식이에요.
- `이름`은 작업한 팀원의 한글 이름이에요. `[N주차]` 바로 뒤에 붙여 써요.
- 주차, type, category, PR 번호 규칙은 그대로예요.
- 예: `[13주차][이찬형] FEAT(Android): 리포트 댓글 영역 구현 (#84)`

## 근거와 대안

- 요청 형식 그대로 `[13주차][이찬형] : 한 일`: 가장 짧지만 기능 추가인지 수정인지와 바뀐 영역이 제목에서 사라져서 쓰지 않았어요.
- `[13주차][이찬형] : [FEAT] 한 일`: 요청 모양에 가깝지만 기존 제목들과 모양이 달라져 목록에서 섞여 보여서 쓰지 않았어요.
- 선택한 형식은 기존 제목 앞에 이름만 더해서, 요청한 `[주차][이름]` 순서를 지키면서 기존 커밋 목록과도 이어져요.

## 가정·한계와 영향

- 요청한 쪽이 `:` 구분과 type 생략까지 정확히 원하면 이 기록을 다시 바꿔요.
- 이미 main에 들어간 커밋과 이미 push한 커밋은 바꾸지 않아요. 열려 있는 PR은 merge 전에 PR 제목만 고치면 돼요.
- GitHub 계정 이름과 한글 이름이 달라서, 이름은 사람이 직접 적어요.

## 검증과 재검토 조건

- `AGENTS.md`와 `CONTRIBUTING.md`의 형식·예시·ADR 링크가 서로 맞는지 확인해요.
- `git diff --check`로 공백 오류를 확인해요.
- 문서만 바뀌어 앱 검사는 실행하지 않아요. PR CI의 `quality` 결과는 PR에서 확인해요.
- 요청한 쪽에서 다른 모양을 지정하면 새 기록으로 바꿔요.

## 반론과 변경 이력

- 2026-11-23: 요청 형식 그대로, 요약 안에 type 넣기, 기존 형식에 이름 더하기를 비교해 이름을 더하는 안을 골랐어요.
