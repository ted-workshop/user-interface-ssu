# Qletter 안드로이드 앱 와이어프레임

Qletter는 이메일과 비밀번호로 로그인한 뒤 YouTube 영상을 요약하고, 내 보관함에서 다시 읽는 안드로이드 앱이에요. 관심 채널을 등록해 새 영상의 리포트를 자동으로 받는 흐름도 제공해요.

이 문서는 숭실대학교 사용자인터페이스 과목 팀프로젝트의 **화면 설계안**이에요. 스마트폰 세로 화면을 기준으로 정보의 순서와 조작을 보여줘요. 예시 제목·수치·주소는 설명용이에요.

제품 목적은 [PRD](01-prd.md), 세부 동작은 [기능 명세](02-functional-spec.md), 이동 흐름은 [사용자 흐름](05-user-flows.md)을 참고해요.

## 1. 화면 지도

| 번호 | 화면 | 사용자가 하는 일 | 연결 기능 |
| --- | --- | --- | --- |
| W-06 | 로그인 | 이메일과 비밀번호로 로그인해요. | F-11 |
| W-07 | 회원가입 | 이메일과 비밀번호로 Qletter 계정을 만들어요. | F-11 |
| W-00 | 영상 요약 | 영상 URL을 넣고 진행 상태를 봐요. | F-01, F-02 |
| W-01 | 홈 | 최근 결과와 자동 처리 현황을 확인해요. | F-09 |
| W-02 | 채널 | 내 관심 채널의 자동 요약을 관리해요. | F-05, F-06 |
| W-03 | 내 보관함 | 내 리포트를 검색하고 골라요. | F-04 |
| W-04 | 리포트 상세 | 글을 읽고 원본 장면을 확인해요. | F-03 |
| W-05 | 설정 | 계정·수신 주소·확인 주기를 관리해요. | F-08, F-11 |

로그인 전에는 W-06을 보여줘요. 로그인 성공 후 W-00으로 이동하고 하단에 `홈 / 요약 / 보관함 / 채널 / 설정` 탭을 제공해요. 상세에서는 상단 뒤로 가기로 이전 화면에 돌아가요. `[버튼]`은 조작 요소, `▾`는 선택·펼침을 뜻해요.

## 2. W-06 · 로그인

```text
┌──────────────────────────────────┐
│                                  │
│             Qletter              │
│                                  │
│ 볼 건 줄이고, 알아야 할 것만.   │
│                                  │
│ YouTube 영상의 핵심을 글로 읽고 │
│ 내 보관함에 모아보세요.         │
│                                  │
│ 이메일                           │
│ [reader@example.com           ] │
│ 비밀번호                         │
│ [••••••••                     ] │
│ [          로그인             ] │
│ [          회원가입           ] │
│                                  │
│ 로그인하면 내 리포트와 채널을   │
│ 다시 불러올 수 있어요.          │
└──────────────────────────────────┘
```

`로그인`을 누르면 입력한 이메일과 비밀번호로 인증해요. 처리 중에는 중복 제출을 막아요. 인증 실패에는 `이메일 또는 비밀번호를 확인해 주세요`, 네트워크 실패에는 `연결을 확인하고 다시 시도해 주세요`를 보여줘요. 유효한 로그인 상태가 있으면 이 화면을 반복해서 거치지 않아요.

`회원가입`은 W-07로 이동해요. 비밀번호는 기본적으로 가리고, 표시·숨기기 조작을 제공해요. 키보드가 열린 상태에서도 입력과 로그인 버튼을 조작할 수 있게 해요.

### W-07 · 회원가입

```text
┌──────────────────────────────────┐
│ [←] 회원가입                     │
│                                  │
│ 내 리포트를 모아볼 계정을 만들어요.│
│ 이메일                           │
│ [reader@example.com           ] │
│ 비밀번호                         │
│ [••••••••                     ] │
│ 비밀번호 확인                    │
│ [••••••••                     ] │
│ [        계정 만들기          ] │
│ 이미 계정이 있나요? [로그인]    │
└──────────────────────────────────┘
```

이메일 형식, 비밀번호 조건, 비밀번호 확인 오류를 해당 입력 근처에 안내해요. 가입 실패 시 이유와 다음 행동을 알려주고 중복 제출을 막아요. 가입 완료 후 `계정을 만들었어요. 로그인해 주세요`를 보여주며 이메일을 채운 W-06으로 돌아가요. 비밀번호는 전달하지 않아요. 뒤로 가기나 `로그인`도 W-06으로 돌아가요.

## 3. W-00 · 영상 요약

```text
┌──────────────────────────────────┐
│ 영상 요약                        │
│                                  │
│ 영상 링크로 핵심부터 읽어보세요.│
│ YouTube 영상 URL                 │
│ [https://youtu.be/…            ] │
│ [          요약하기           ] │
│                                  │
│ 영상 전체를 요약해 보관해요.    │
│ 이메일은 자동으로 보내지 않아요.│
│                                  │
│ ─ 요청 상태 ──────────────────  │
│ 요약 중                          │
│ 예시: 일하는 방식을 바꾸는 AI   │
│ 앱으로 돌아와 결과를 확인하세요.│
│                                  │
├──────────────────────────────────┤
│ 홈  ●요약  보관함  채널  설정   │
└──────────────────────────────────┘
```

키보드가 열려도 입력과 제출 버튼을 조작할 수 있게 해요. 요청 카드에는 대상 영상을 표시해 입력창의 새 주소와 구분해요. 완료한 결과는 `리포트 읽기`로 열어요.

| 상태 | 안내·행동 |
| --- | --- |
| 입력 없음 | URL을 넣기 전에는 제출을 비활성화해요. |
| 잘못된 주소 | 입력값을 유지하고 영상 주소인지 확인하도록 안내해요. |
| 같은 계정의 기존 결과 있음 | `이미 만든 리포트가 있어요`와 `[리포트 읽기]`를 보여줘요. |
| 대기·요약 중 | 상태와 영상 제목을 보여주고 동일 요청을 중복 제출하지 않아요. |
| 완료 | `[리포트 읽기]`, `[다른 영상 요약]`을 제공해요. |
| 영상 접근 실패 | 주소나 공개 여부를 확인하도록 안내해요. |
| 일시적 처리 실패 | 이유와 `[다시 시도]`를 보여줘요. |
| 상태 조회 실패 | `[상태 다시 확인]`을 제공하며 새 분석을 시작하지 않아요. |

## 4. W-01 · 홈

```text
┌──────────────────────────────────┐
│ 홈                               │
│ 내 채널 3개 · 요약 중 1건       │
│ 메일 발송 실패 1건              │
│                                  │
│ [       채널 지금 확인        ] │
│ 마지막 확인 10분 전             │
│ 다음 확인 5분 뒤                │
│                                  │
│ 최근 리포트          [전체 보기]│
│ ┌──────────────────────────────┐ │
│ │ 일하는 방식을 바꾸는 AI     │ │
│ │ 직접 요약 · 오늘           │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 읽기 습관을 만드는 법      │ │
│ │ 채널 자동 · 메일 발송 실패 │ │
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│ ●홈  요약  보관함  채널  설정   │
└──────────────────────────────────┘
```

홈에는 로그인한 사용자의 결과만 보여줘요. 처음에는 `영상 링크로 첫 리포트를 만들어보세요`와 요약 탭 이동을 제공해요. `채널 지금 확인`은 등록 채널 확인이며 직접 URL 요약과 구별해요.

## 5. W-02 · 채널

```text
┌──────────────────────────────────┐
│ 내 채널                          │
│ [채널 주소 또는 @핸들         ] │
│ [            찾기             ] │
│                                  │
│ 검색 결과: 예시 지식 채널       │
│ 첫 확인의 기존 영상은 건너뛰고,│
│ 이후 새로 발견한 영상을 요약해요.│
│ [취소]             [채널 등록] │
│                                  │
│ ─ 등록한 채널 ────────────────  │
│ 예시 지식 채널      [켜짐] [⋮] │
│ 예시 학습 채널      [중지] [⋮] │
├──────────────────────────────────┤
│ 홈  요약  보관함  ●채널  설정   │
└──────────────────────────────────┘
```

수신 설정이 없으면 설정 탭으로 안내해요. 더보기 메뉴에서 삭제할 수 있고, 삭제 확인 대화상자에는 `새 영상 확인과 대기 메일 재시도가 멈춰요. 기존 리포트는 남아요`를 보여줘요. 일시 중지에도 같은 중단 범위를 안내해요.

## 6. W-03·W-04 · 내 보관함과 상세

```text
┌──────────────────────────────────┐   ┌──────────────────────────────────┐
│ 내 보관함                        │   │ [←] 리포트                       │
│ [제목으로 찾기                ] │   │ 읽기 습관을 만드는 법           │
│ [채널 ▾] [직접/자동 ▾]          │   │ 예시 학습 채널 · 오늘           │
│ [발송 상태 ▾]                   │   │ 직접 요약 · 발송 안 함          │
│                                  │   │ [원본 영상 ↗] [목차 ▾]          │
│ 읽기 습관을 만드는 법           │   │                                  │
│ 직접 요약 · 오늘                │   │ 세 줄 요약                       │
│ ──────────────────────────────   │   │ 1. 핵심 주장                     │
│ 일하는 방식을 바꾸는 AI          │   │ 2. 중요한 설명                   │
│ 채널 자동 · 어제                │   │ 3. 기억할 점                     │
│                                  │   │                                  │
│                                  │   │ 주제별 설명 [03:42 ↗]            │
│                                  │   │ 사례와 맥락을 풀어쓴 본문…       │
├──────────────────────────────────┤   │                                  │
│ 홈  요약  ●보관함  채널  설정   │   │ 핵심 정리와 생각해볼 질문        │
└──────────────────────────────────┘   └──────────────────────────────────┘
```

목록의 항목을 누르면 전체 화면 상세로 이동해요. 뒤로 가면 검색·필터·스크롤 위치를 유지한 목록으로 돌아가요. 원본 링크는 YouTube 앱 또는 브라우저로 열고, 돌아오면 읽던 위치를 유지해요.

검색 결과 없음, 본문 로딩·조회 실패, 메일 발송 실패는 각각 다르게 표시해요. 메일에 문제가 있어도 본문은 읽을 수 있어요.

## 7. W-05 · 설정과 로그아웃

```text
┌──────────────────────────────────┐
│ 설정                             │
│ 내 계정                          │
│ reader@example.com               │
│ [로그아웃]                       │
│                                  │
│ 채널 리포트 수신 이메일         │
│ [reader@example.com           ] │
│ [추가]                           │
│ 직접 요약은 이메일 없이 읽어요.│
│                                  │
│ 새 영상 확인 주기               │
│ [15분마다 ▾]                    │
│                                  │
│ 화면 테마                        │
│ [시스템 설정 따르기 ▾]          │
│ [       변경 사항 저장        ] │
├──────────────────────────────────┤
│ 홈  요약  보관함  채널  ●설정   │
└──────────────────────────────────┘
```

로그인 이메일과 리포트 수신 주소는 역할을 구분해요. 회원가입하거나 로그인했다고 이메일 발송 설정을 자동으로 켜지 않아요. 주소·주기 변경은 저장 후 반영하고, 주기 수치와 선택지는 팀에서 정해요.

로그아웃 확인에는 `보관한 리포트는 계정에 남아요. 채널 자동 요약은 계속될 수 있어요`와 `[취소] [로그아웃]`을 제공해요. 로그아웃 후 뒤로 가기로 개인 화면을 다시 열 수 없게 해요.

## 8. Android 사용성 검토

- 처음 온 사람이 회원가입·로그인을 거쳐 URL 입력과 첫 결과까지 도달할 수 있나요?
- Android 뒤로 가기와 상단 뒤로 가기가 예측한 곳으로 이동하나요?
- 키보드·큰 글자 설정에서도 입력과 주요 버튼을 사용할 수 있나요?
- 앱 재진입·화면 회전으로 요청이 중복되거나 읽던 위치를 잃지 않나요?
- 입력 오류, 인증 실패, 네트워크 끊김, 분석 실패를 구분해 안내하나요?
- TalkBack에서 입력·버튼·처리 상태를 이해할 수 있나요?
- 계정 전환 후 이전 사용자의 기록이 보이지 않나요?
