# ADR-0034: 리포트와 댓글은 리포트별 권한 행이 있는 사용자만 읽고 써요

- 상태: 확정
- 작성·확정일: 2026-11-09
- 확정 근거: 리뷰에서 kitae0522가 채널 구독자 열람 대신 리포트별 권한을 제안했고, 사용자가 2026-11-09에 그 안으로 정했어요. #23 본문도 같은 방향으로 바뀌었어요.
- 관련 기록: [ADR-0020](0020-shared-analysis-and-report-permissions.md)의 공통 보고서·개인 권한, [ADR-0026](0026-report-read-http.md)의 상세 조회를 적용해요. PR #48의 전체 공개·순번 승계 설계(초안 ADR-0031)와 PR #52의 채널 구독자 열람 초안은 머지되지 않았고 이 기록으로 대체해요.
- 구현·검증 상태: 로컬 구현과 workerd 검사를 마쳤어요. 원격 CI·배포·Android 연결은 확인하지 않았어요.

## 문제와 현재 상태

[#23](https://github.com/ted-workshop/user-interface-ssu/issues/23)은 같은 리포트에 접근할 수 있는 사용자끼리 댓글로 의견을 나누게 해요.
같은 영상을 요청한 A와 B는 이미 같은 `report_id`에 각자의 개인 권한 행을 받아요.
처음 안이었던 전체 공개는 공개한 사람·순번·철회 규칙이 복잡했고, 다음 안인 채널 구독자 열람은 구독 해지 시점의 규칙이 애매했어요.
또 운영 코드는 `videos.channel_id`를 채우지 않아 채널 기준 열람이 실제로 동작하지 않았어요.

## 결정

- 리포트 조회와 댓글 조회·작성·삭제는 그 리포트의 개인 권한 행(`audience='user'`)이 있는 사용자만 해요. 그 외에는 없는 리포트와 같은 404예요.
- 채널 구독은 알림·자동 요약 요청의 개념이에요. 구독을 해지해도 이미 받은 리포트의 권한 행을 회수하지 않아요.
- 댓글 삭제는 지금 읽기 권한이 있는 작성자 본인만 하고 `deleted_at` 표시로 남겨요. 권한 행이 사라지면 작성자여도 404예요.
- 댓글 작성은 권한 확인과 저장을 `INSERT ... SELECT ... WHERE` 한 문장으로 해서, 그 사이에 권한이 사라져도 500이 아니라 404예요.
- `0008_report_comments.sql`에서 `comment_public`을 개인 권한 행만 인정하는 `comment_reader`로 바꾸고, 쓰지 않는 `authenticated` 공개 규칙 행을 지워요.
- 댓글 수정, 읽기 전용·작성 분리 같은 세부 권한, RBAC는 두지 않아요.

## 근거와 대안

- 리포트 접근은 이미 리포트 단위 관계예요. 같은 구조를 그대로 쓰면 새 상태나 테이블 없이 댓글을 붙일 수 있어요.
- 채널 구독자 열람은 `stopped_at`, 재구독 시 소급 여부를 사용자가 이해하기 어렵고, 영상과 채널을 연결하는 작업이 먼저 필요해요.
- `authenticated` 값 자체를 스키마에서 없애려면 FK가 걸린 `report_permissions`를 다시 만들어야 해서, 행만 지우고 API와 trigger에서 쓰지 않아요.

## 가정·한계와 영향

- 같은 영상을 요청하지 않은 사용자는 채널을 구독해도 리포트와 댓글을 볼 수 없어요.
- 구독자끼리 둘러보는 목록은 없어요. 필요하면 영상과 채널 연결을 먼저 만든 뒤 별도로 다뤄요.
- 보관함에서 빼는 API는 아직 없어서, 권한이 사라진 경우는 테스트에서 권한 행을 직접 지워 확인해요.

## 검증과 재검토 조건

- 2026-11-09 Windows 11 로컬에서 workerd 351개, Biome, 타입 검사를 통과했어요.
  같은 영상을 요청한 A/B의 댓글 주고받기와 페이지, 권한 없는 사용자와 채널만 구독한 사용자의 404,
  본인 댓글만 삭제·삭제 표시 보존, 권한이 사라진 작성자의 삭제 거부, 입력 오류, DB trigger를 다뤄요.
- 리포트를 구독자나 다른 사용자와 나눠야 하는 요구가 생기면 리포트별 권한 부여 방식을 다시 검토해요.

## 반론과 변경 이력

- 2026-11-09: 리뷰 의견을 받아 채널 구독자 열람·둘러보기·`stopped_at`을 빼고 리포트별 권한으로 바꿨어요.
