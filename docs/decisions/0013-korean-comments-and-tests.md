# ADR-0013: 주석과 테스트 이름은 한국어로 작성해요

- 상태: 확정
- 작성·확정일: 2026-10-25
- 확정 근거: 사용자가 모든 주석과 테스트를 한국어로 작성하도록 요청했어요.
- 관련 기록: [ADR-0010](0010-commit-title-format.md), [ADR-0012](0012-gmail-smtp-email-foundation.md)
- 구현·검증 상태: 직접 관리하는 주석·테스트 이름과 저장소 규칙을 수정했어요. 전체 로컬 검사와 Android 계측 테스트 APK 빌드를 통과했어요. 기기 계측 테스트 실행은 하지 않았어요.

## 문제와 현재 상태

팀 문서는 한국어지만 메일 모듈의 주석과 API·공통 도구·Android 테스트 이름은 영어였어요.
사용자는 주석과 테스트도 한국어로 통일하도록 요청했어요. 새 메일 코드에만 적용하면 기존 테스트 출력에는 영어 설명이 남아요.

## 결정

- 직접 작성하는 주석과 테스트 설명·이름은 한국어로 적어요. 이 규칙을 [AGENTS.md](../../AGENTS.md)에 반영해요.
- TypeScript 테스트의 설명 문자열과 Java의 `@Test` 메서드 이름을 한국어로 바꿔요.
  설명 문장은 한국어 해요체로 쓰고 API·라이브러리 이름은 필요한 곳에서 유지해요.
- 기존 API·공통 도구·Android의 주석과 테스트에도 적용해요. 테스트의 입력·검증 조건과 제품 동작은 바꾸지 않아요.
- Wrangler 생성 타입과 Gradle Wrapper처럼 도구가 생성·배포하는 파일은 원문을 유지해요.
  명령·프로토콜·응답 코드·공급자 오류 fixture와 그 검증에 필요한 원문도 유지해요.

## 근거와 대안

주석과 테스트 출력에서 동작·실패 이유를 한국어로 바로 읽을 수 있어야 한다는 사용자 기준을 적용해요.
직접 관리하는 테스트와 주석 전체를 확인했으며, 변경 대상은 메일 코드 외에도 기존 공통 도구와 Android 테스트에 있어요.
실제 변경과 근거는 [API 테스트](../../apps/api/test/email.test.ts), [검증 도구 테스트](../../apps/api/tools/email.test.ts),
[공통 검사 테스트](../../scripts/checks.test.ts), [Android 연결 테스트](../../apps/android/app/src/testDebug/java/kr/ac/ssu/qletter/HealthClientTest.java)에서 확인해요.

영어를 유지하면 외부 문서와 용어가 같다는 장점이 있지만 사용자 요청에 맞지 않아 선택하지 않아요.
생성 파일까지 번역하면 `wrangler types --check`와 Wrapper 재생성으로 덮어써지는 문제가 생기므로 직접 관리하는 설명에 적용해요.
별도 번역 도구나 언어 검사 의존성은 추가하지 않아요. 코드 검토와 기존 검사 경로를 사용해요.

## 가정·한계와 영향

Java 테스트 이름은 JUnit이 찾는 메서드 식별자도 바뀌어요. 클래스 이름·`@Test` 표식·검증 내용은 유지하고 빌드와 테스트 실행으로 확인해요.
기존 테스트 결과를 이름으로 검색하거나 개별 메서드를 지정해 실행할 때는 새 한국어 이름을 사용해야 해요.
런타임 API·DB·메일 발송·배포 설정은 바꾸지 않아요. Android 테마와 Gradle 설정에서는 주석만 번역해요.

## 검증과 재검토 조건

`mise run check`로 API·Bun·Android·인프라 검사를 실행하고, Android 테스트 APK도 빌드해 계측 테스트의 한국어 메서드 이름이 컴파일되는지 확인해요.
영문 주석과 테스트 설명이 남았는지 검토하고, `git diff --check`와 최종 diff·Git 상태를 확인해요.
실제 메일을 재발송하거나 에뮬레이터·실제 기기의 계측 테스트를 실행한 것으로 보고하지 않아요.

2026-10-25 `ANDROID_HOME=<개인 SDK 경로> mise run check`를 통과했어요. workerd 22개·Bun 도구 8개·공통 도구 39개와 Android 로컬 테스트 8개가 통과했어요.
Android 포맷·lint·debug 빌드와 두 Terraform root의 backend 없는 검사도 통과했어요.
`assembleDebugAndroidTest`로 계측 테스트 APK를 빌드했어요. Java 테스트 메서드 9개 중 로컬 테스트 8개는 실제 실행 결과를, 계측 테스트 1개는 컴파일 결과만 확인했어요.
Wrangler 생성 타입의 drift 검사와 주석을 제외한 제품 코드·Gradle 설정 값의 동일성 검사도 통과했어요.

팀의 작성 언어나 외부 협업 요구가 바뀌면 언어 기준을 다시 검토해요. 생성 파일의 소유권과 프로토콜 원문은 계속 구분해요.

## 반론과 변경 이력

- 2026-10-25: 사용자의 한국어 작성 요청을 채택하고 기존 코드의 주석과 테스트에도 적용했어요.
- 2026-10-25: 사용자의 요청에 따라 한국어 정리를 메일 PR #20에서 분리했어요. #20을 선행 PR로 두고 이 기록·작성 규칙·주석·테스트 이름 변경을 후속 PR에서 함께 검토해요. 한국어 작성 결정은 유지해요.
