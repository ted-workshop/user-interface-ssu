# ADR-0029: Gemini 운영 모델을 3.8 Flash로 바꿔요

- 상태: 확정
- 작성·확정일: 2026-11-03
- 확정 근거: 사용자가 공식 문서를 다시 확인한 뒤 3.8 Flash로 가기로 정했어요.
- 관련 기록: [ADR-0015](0015-gemini-production-settings.md)의 시작 모델 값을 바꿔요. 생성 조건은 [ADR-0017](0017-report-generation-parity.md)을 그대로 따라요.
- 구현·검증 상태: 서버 허용 목록과 개발용 기본 모델에 3.8을 추가하고 로컬 검사를 실행했어요(아래 검증 참고).
  GitHub `GEMINI_MODEL` 값 변경·재배포·실제 생성 성공은 하지 않았어요.

## 문제와 현재 상태

`gemini-3.6-flash`는 10월 30일~11월 3일 같은 설정의 반복 실행이 모두 503이었어요.
3.8 Flash는 허용 목록에 없어서 시험할 때 한 줄을 임시로 추가해야 했고 첫 시험은 응답 없이 600초 시간 초과였어요.
처음에는 3.8이 Agentic을 지원하지 않는다는 전달에 따라 3.6 고정을 정했지만, 공식 문서를 다시 보니 지원 모델에 3.8이 있었어요.

## 결정

- 운영·검증 모델을 `gemini-3.8-flash`로 바꿔요. 서버 허용 목록에 추가하고 `wrangler.jsonc`의 개발용 기본값도 바꿔요.
- 기존 허용 모델(3.5 flash-lite, 3.6, 3.7)은 그대로 둬요. 프롬프트·Interactions·Agentic·600초·SDK 재시도 옵션은 바꾸지 않아요.
- 모델·API 경로의 자동 전환은 계속 하지 않아요.
- 운영 값은 GitHub `production`의 `GEMINI_MODEL` Variable이에요. 이 기록은 그 값을 바꾸거나 배포하지 않아요.

## 근거와 대안

2026-11-03 확인한 [영상 이해 문서](https://aistudio.google.com/docs/video-understanding)는 Agentic 지원 모델에
"Gemini 4 Argon, 3.8 Flash, 3.6 Flash, 3.5 Flash Lite"를 나열해요(요약 도구로 가져온 내용이고 문서 전체를 직접 읽지는 않았어요).
모델 조회(`models/gemini-3.8-flash`)는 같은 키로 HTTP 200이고 `generateContent`를 지원한다고 표시됐어요.
3.6과 3.8의 요금이 같다는 말은 사용자가 전달했고 공식 요금표로 확인하지 않았어요.

- 3.6 유지: 허용 목록이 이미 있고 변경이 없어요. 하지만 반복 503이고 사용자가 바꾸기를 원해요.
- 3.7 사용: 허용 목록에 있지만 위 문서의 Agentic 지원 목록에는 없어요.

## 가정·한계와 영향

- 3.8의 생성 성공은 한 번도 확인하지 못했고 첫 시험은 600초 시간 초과였어요. 이 변경이 503 또는 시간 초과를 해결한다는 증거는 없어요.
- 모델은 생성 설정의 일부라서(ADR-0017) 3.8로 만든 보고서는 3.6 보고서와 다른 생성 설정으로 취급돼요. 기존 보고서를 다시 만들지 않아요.
- 배포하려면 `GEMINI_MODEL` Variable을 바꿔야 해요. 바꾸지 않으면 운영은 이전 모델로 남아요.

## 검증과 재검토 조건

`mise run api:check`로 허용 목록과 전달 계약을 검사해요. 새 키로 3.8 생성이 성공하는지는 #5에서 따로 확인해요.
3.8이 계속 시간 초과나 503이면 모델을 다시 검토해요.

## 반론과 변경 이력

- 2026-11-03: 3.8 Agentic 미지원이라는 전달로 3.6 고정을 먼저 정했다가, 공식 문서 대조 후 3.8로 바꿨어요.
