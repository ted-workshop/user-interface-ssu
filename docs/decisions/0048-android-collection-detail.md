# ADR-0048: 모음 상세는 20개씩 이어 받고 줄마다 빼기를 둬요

- 상태: 확정
- 작성일: 2026-11-23
- 확정 근거: #60 범위에서 정한 구현 판단이에요. 피그마에 빼기 화면이 없어 PR 리뷰에서 다시 확인해요.
- 관련 기록: [ADR-0029](0029-collections-http.md), [ADR-0038](0038-android-foundation.md), [ADR-0039](0039-android-feature-packages.md), [ADR-0045](0045-android-add-to-collection-sheet.md)
- 구현·검증 상태: 구현, 로컬 검사, 에뮬레이터 기기 테스트를 했어요. 실제 TalkBack 확인과 리포트 상세 열기(#28)는 남아 있어요.

## 문제와 현재 상태

- 모음 상세는 리포트를 100개까지만 받고, 더 있으면 "100편까지 보여요" 안내만 했어요.
- 모음에서 리포트를 빼는 동작이 화면에 없었어요. API(`DELETE /v1/collections/{id}/reports/{reportId}`)는 있어요.
- 피그마 60:88에는 리포트 줄만 있고 빼기 버튼이나 확인창이 없어요.
- 목록이 남은 높이를 나눠 써서, 가로 화면에서는 목록 높이가 0이 됐어요.

## 결정

- 서버 기본값처럼 20개씩 받고, 목록 아래 `리포트 더 보기`로 다음 20개를 붙여요. 받는 중에는 다시 보내지 않아요.
- 줄마다 제목 오른쪽에 `빼기` 글자 버튼을 두고, 확인창(`ConfirmDialog`)을 거쳐 빼요. 리포트는 내 리포트에 남는다고 알려요.
- 빼는 동안 그 줄의 버튼과 `이름 바꾸기`를 잠가요. 이름 바꾸기 응답의 개수와 늦게 온 빼기 성공이 겹치면 헤더 개수가 두 번 줄어서예요. 성공하면 줄을 지우고 헤더 개수를 1 줄이고, 모음 목록에 다시 불러오라고 알려요. 실패하면 줄을 남기고 짧게 알려요.
- 받은 리포트를 다 뺐는데 서버에 더 있으면, 빈 화면 대신 다음 20개를 받아요.
- 목록과 요청은 `CollectionDetailViewModel`이 들고 있어서 회전해도 이어 받아요(#68·#82·#84와 같은 방식).
- 화면 전체를 한 번에 스크롤해요. 목록은 스크롤 안에서 모든 줄을 그려요.

## 근거와 대안

- 끝까지 내리면 자동으로 받기: 버튼이 없어 깔끔하지만, 실패했을 때 다시 시도할 자리가 따로 필요하고 테스트가 어려워서 쓰지 않았어요.
- 빼기 버튼을 줄 맨 오른쪽 세로 칸에 두기: 처음엔 이렇게 했는데, 폰 너비에서 `발송 실패`나 날짜가 잘렸어요. 제목 줄로 옮기면 채널·날짜 줄이 피그마처럼 전체 너비를 써요.
- 길게 눌러 빼기: 자리는 안 차지하지만 눈에 안 보이고 TalkBack 사용자가 찾기 어려워서 쓰지 않았어요.
- 확인창 없이 빼고 되돌리기 안내: 되돌릴 수 있는 동작이라 가볍지만, 되돌리기 요청과 상태가 더 필요해서 이번에는 확인창을 썼어요.
- 목록만 스크롤하기: 줄을 재활용해서 효율적이지만 가로 화면에서 목록이 사라져서 쓰지 않았어요.

## 가정·한계와 영향

- 스크롤 안의 목록은 줄을 재활용하지 않아요. 20개씩 받아서 감수해요. 수백 개를 넘게 보는 사용이 많아지면 다시 정해요.
- 빼기 버튼은 피그마에 없어요. 디자인에서 자리·모양이 정해지면 그에 맞춰요.
- 서버가 전체 개수를 다시 주지 않아서, 헤더 개수는 화면을 연 때의 개수에서 뺀 만큼 줄여요. 다른 기기에서 바뀐 개수는 다시 열어야 맞아요.
- `CollectionApi.Page`에 `nextCursor`를 더했어요. 모음 목록과 담기 시트는 지금처럼 100개와 `hasMore`를 써요.

## 검증과 재검토 조건

- `CollectionDetailActivityTest`: 더 보기를 두 번 눌러도 한 번만 받기, 빼면 목록·개수·결과 반영, 빼는 중 회전해도 한 번만 보내기
- 확인용 시나리오(커밋 안 함): 빈 목록, 불러오기·더 보기 실패와 다시 시도, 빼기 실패, 확인창을 연 채 회전, 마지막 리포트 빼기, 가로, 글꼴 2.0과 긴 제목, 발송 실패 표시, 빼기 버튼 읽기
- 피그마에 빼기 디자인이 생기거나, 리뷰에서 다른 위치를 정하면 바꿔요.

## 반론과 변경 이력

- 2026-11-23: 처음 만든 버전에서 빼기 버튼이 `발송 실패`를 자르고, 가로 화면에서 목록이 사라지는 것을 스크린샷으로 확인해 위치와 스크롤 구조를 바꿨어요.
- 2026-11-24: PR #87 리뷰에서 빼기와 이름 바꾸기가 겹치면 헤더 개수가 두 번 준다는 지적을 받아, 빼는 동안 이름 바꾸기를 잠갔어요.
